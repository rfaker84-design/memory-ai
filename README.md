# 忆见 MemoryAI

通过 AI 保存亲人的声音、故事与记忆。

## 技术栈

- Next.js 15 (App Router)
- TypeScript
- Tailwind CSS 4
- 响应式设计

## 快速开始

```bash
npm install
npm run dev
```

在浏览器中打开 [http://localhost:3000](http://localhost:3000) 查看效果。

## 脚本

| 命令 | 说明 |
|------|------|
| `npm run dev` | 启动开发服务器 |
| `npm run build` | 构建生产版本 |
| `npm run start` | 启动生产服务器 |
| `npm run lint` | 运行 ESLint 检查 |
