# Sprint15B 创建 TA 一镜到底体验

创建页固定为身份、记忆、素材与授权、预览与创建四阶段。存在体和轻量表单始终位于同一暗色中性场景；步骤切换 360ms、位移 14px，呼吸缩放 1.2%，并尊重 reduced-motion。

草稿只保存文本字段，授权每次重新确认，照片和声音永不进入 localStorage。素材通过 `/api/media/upload` 上传；接口返回 404、501 或 503 时显示“素材上传服务尚未就绪”，不伪造 URL 或成功状态。最终创建继续调用 `/api/memories`，成功响应中的 id 用于进入详情或对话。

创建按钮具备单次请求锁。已成功的响应不会再次提交；服务明确失败后允许用户重试。端到端的跨网络超时幂等仍依赖 `/api/memories` 支持持久化 idempotency key。
