# 忆见 V1 平台架构冻结声明

## 1. 冻结结论

MemoryAI V1 平台底层架构在 Sprint12 后正式冻结。

## 2. 冻结范围

以下架构不允许随意绕过或推翻：

- 领域服务架构
- 仓库与数据源架构
- AI能力中心
- 事件总线
- 记忆引擎
- 情绪引擎
- 提示词架构
- 长期记忆架构
- 媒体资源架构
- 存储服务提供器
- 权限检查
- 审计日志
- 风险控制
- 授权合规
- 部署运维规范

## 3. 后续开发铁律

所有新功能必须遵守：

1. 页面不得直接访问数据库
2. API 不得绕过领域服务
3. AI 能力不得直接调用第三方平台
4. 文件上传不得绕过媒体资源架构
5. 高风险能力必须先检查授权合规
6. 关键行为必须写审计日志
7. 用户访问必须经过权限检查
8. 风险内容必须进入风险控制架构
9. 上线必须通过健康检查
10. 部署必须支持回滚

## 4. 允许继续完善但不得推翻的内容

- RLS
- 限流
- 缓存
- 监控告警
- CI/CD
- 后台管理
- 支付订单
- 邀请裂变

## 5. 下一阶段

正式进入产品能力开发阶段：

- 首页与视觉系统
- 创建亲人档案与素材上传
- 真实 AI 聊天
- AI 声音
- AI 形象
- 数字人
- 支付会员
- 后台运营
