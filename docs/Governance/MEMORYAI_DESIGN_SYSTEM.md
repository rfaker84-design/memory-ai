# MemoryAI（忆见）设计系统规范

文档状态：ACTIVE

规范级别：DESIGN BASELINE

2026-09-06 同步：当前页面基准见 Master Blueprint 第 0 节；既有批准布局、人物素材、Motion 和逐页验收要求继续有效。

---

## 1. 设计目标

MemoryAI 的界面目标：

- 温暖
- 安静
- 克制
- 沉浸
- 高级
- 真实
- 有生命感

设计必须服务于：

- 思念
- 陪伴
- 记忆
- 存在感

禁止将产品设计为：

- SaaS Dashboard
- Admin Panel
- AI Tool Website
- Crypto Website
- Gaming HUD
- 普通聊天软件
- 传统纪念馆

---

## 2. 移动端优先

主要设计目标：

- iPhone
- Android
- 移动浏览器

所有核心页面首先以移动端体验验收。

桌面端是自然扩展。

禁止先设计 Desktop 再压缩到 Mobile。

必须考虑：

- `safe-area-inset-top`
- `safe-area-inset-bottom`
- 动态浏览器地址栏
- 触摸区域
- 单手操作
- 软键盘
- 输入框顶起
- 底部导航

---

## 3. 页面结构

移动端主导航固定为四个一级入口：

- 首页
- 相伴
- 拾忆
- 我的

禁止未经明确指令增加第五个一级 Tab。

页面必须有明确唯一视觉焦点。

一个屏幕内禁止出现多个同级主 CTA。

信息层级必须清晰。

---

## 4. 色彩方向

当前页面按已有批准实现区分：

- 首页和相伴以自然人物影像为主，叠加克制的暖暗遮罩。
- 拾忆、创建和我的使用 Warm Ivory 暖象牙、纸张与生活材质。
- 暖金、低饱和琥珀和肤色光作为局部强调。
- AI 提示须稳定可读；不能靠降低文字透明度达到“轻”的效果。

早期“所有页面主背景深色”已被上述批准页面替代，不得据此将暖象牙页面改回黑金或星空。不新增科技蓝、紫色渐变、彩虹、Neon Cyberpunk 或大面积 Glow。

---

## 5. 光影

优先使用：

- 局部光
- 环境光
- 柔和辉光
- 人物轮廓光
- 空间雾
- 自然暗部

禁止：

- 大面积 Glow
- 廉价 Outer Shadow
- 高饱和霓虹
- 多个颜色同时发光

光影必须建立空间层次。

---

## 6. 空间层级

视觉层级建议：

- L0 Background Space
- L1 Atmosphere
- L2 Environment Light
- L3 Primary Subject
- L4 Primary Content
- L5 Interaction Layer
- L6 Navigation

禁止所有元素处于同一视觉平面。

优先通过：

- 景深
- 尺寸
- 透明度
- 光照
- 模糊
- 位移

建立层级。

禁止依赖大量边框分区。

---

## 7. 卡片

卡片不是默认容器。

只有存在明确内容分组时才使用卡片。

禁止：

- 所有内容卡片化
- 大量 1px border
- Dashboard Grid
- 统一圆角矩形铺满页面

卡片优先使用：

- 背景层次
- 轻微材质
- 局部光
- 空间间距
- 必要时使用玻璃材质

玻璃效果必须克制。

---

## 8. 圆角

圆角必须统一。

禁止页面内随机出现：

- 8px
- 12px
- 18px
- 22px
- 28px
- 32px

所有正式组件必须使用 Design Token。

创建视觉实现时优先复用现有 Token。

如果项目中不存在统一 Token：

- 不得在单次任务中擅自建立完整 Design Token 系统。
- 报告缺失。
- 等待独立任务处理。

---

## 9. 字体与文字

中文必须优先保证移动端可读性。

禁止使用大量超细字体。

正文必须保持稳定阅读。

标题允许更强情绪表达。

禁止：

- 大量全大写英文
- 大量装饰英文
- 无意义英文副标题
- AI 产品常见技术宣传词堆叠

文字必须像人在说话。

---

## 10. 留白

留白是核心视觉元素。

禁止为了填满屏幕增加内容。

页面必须有呼吸空间。

内容密度必须低于普通 SaaS 产品。

重要内容周围必须保留视觉缓冲区。

---

## 11. 图片与人物

亲人形象属于最高优先级视觉内容。

人物必须：

- 真实
- 清晰
- 自然
- 具有存在感

禁止：

- 廉价 AI 感
- 过度磨皮
- 塑料皮肤
- 卡通化
- 默认模糊人物
- 用粒子代替人物
- 用发光人形代替真实人物

当真实人物素材不可用时：

- 保持结构占位。
- 不得自行生成廉价替代视觉。

---

## 12. 页面一致性

以下页面必须属于同一个产品世界：

- Splash
- 首页
- 创建亲人
- 聊天
- 记忆
- 我的

禁止每个页面独立选择设计风格。

禁止：

- 首页宇宙风
- 聊天微信风
- 创建页 SaaS 风
- 我的页面后台风

所有页面必须共享：

- 色彩语言
- 光影逻辑
- 空间层级
- 字体节奏
- Motion 节奏

---

## 13. 设计权限

AI Coding Agent 无权自行重新设计页面。

如果任务提供：

- 截图
- 设计稿
- Motion Spec
- 布局规范
- 参数

必须严格执行。

如果设计信息不足：

- 优先保持现有设计一致。
- 不得自由发挥成新的设计方向。
