## 1. 如何使用

1. 用户本人先填写 `wave1/01-entity-email-intake.md`，冻结唯一发布主体和统一身份字段。
2. 按本文件的“最晚启动日期”真实发起申请；保存官方回执、原始状态名称和日期。
3. 证件扫描件、身份证、银行卡、密码、验证码、签名原件不得进入 Git，只存访问受控的外部证据库。
4. Git 台账只登记脱敏证据路径、SHA-256、核验人和时间。
5. `材料已备`、`已提交`、`审核中`均不等于`已通过`。只有原始证据满足关闭标准时才能把 Gate 标为`已关闭`。
6. 任何名称、经营范围、备案或权利模板均应由属地登记机关、接入商或专业律师最终确认。

## 6. 官方依据和时限

- [Apple组织注册要求](https://developer.apple.com/help/account/membership/program-enrollment)：法人实体、D-U-N-S、具有法律约束权限的申请人、同域企业邮箱、有效官网；Apple可能要求经认证的公司文件。
- [Apple D-U-N-S要求和时限](https://developer.apple.com/help/account/membership/D-U-N-S/)：查询需法定名称、总部/通信地址和工作联系人；申请后最多5个工作日，Apple同步最多2个工作日。
- [计算机软件著作权登记办法](https://www.ncac.gov.cn/xxfb/flfg/bmgz/202410/t20241015_869486.html)：申请表、程序和文档鉴别材料、证明文件；源程序和一种文档前后各连续30页；受理后60日内审查。
- [APP备案政策解读](https://hunca.miit.gov.cn/zwgk/zcwj/zcjd/art/2023/art_888eed9c8e29444b8adf4787e2b26151.html)：新APP先备案后开展业务，材料齐全准确后20个工作日内备案。
- [小米企业开发者账号标准](https://dev.mi.com/xiaomihyperos/documentation/detail?pId=1731)：企业信息与营业执照/公示系统一致，企业和申请人均需实名认证。
- [小米账号注册流程](https://dev.mi.com/docs/appsmarket/distribution/account_register/)：公开说明身份审核通常1～3个工作日。
- [华为应用市场分发流程](https://developer.huawei.com/consumer/cn/appgallery/devstart/)：注册账号、实名认证、包体、隐私声明、资质和APP备案。
- [人工智能生成合成内容标识办法](https://www.cac.gov.cn/2025-03/14/c_1743654685899683.htm)：显式标识和文件元数据隐式标识。

这些链接用于准备材料，不证明本项目已提交、已受理、已备案或已上架。
