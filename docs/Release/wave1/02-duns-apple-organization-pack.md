## 3. 授权书要点

申请人不是法定代表人/创始人时，由有权人签署正式授权书，至少写明：

- 公司法定名称和USCI（完整编号仅在签署原件）。
- 被授权人姓名、职务、公司邮箱和电话。
- 有权代表公司注册Apple Developer Program、接受协议、支付会费。
- 是否可管理证书、Identifiers、Profiles、App Store Connect用户和应用提交。
- 授权期限、撤销方式、签署人权限和公司公章。
- 独立核验联系人姓名、职位和电话。

## 4. Apple申请步骤

1. 使用Account Holder的Apple Account登录，确认2FA。
2. D-U-N-S同步满2个工作日后选择Organization注册。
3. 逐字使用法定实体名称和D-U-N-S信息。
4. 填写公司域名工作邮箱、官网和核验联系人。
5. 保存Enrollment ID和原始状态，不记录密码/验证码。
6. 响应Apple电话或邮件补件；若要求认证/公证文件，交由本人或律师办理。
7. 验证通过后再接受协议并付款。
8. 收到会员确认并能以组织Account Holder进入开发者后台后，才能申请关闭G-03。

Apple未给组织核验固定完成时限。项目估算：资料一致且无补件时5～15个工作日；补件、公证、D&B信息更正会延长。

最晚启动：材料准备2026-07-29；D-U-N-S同步后立即提交，最晚不晚于2026-08-07。
