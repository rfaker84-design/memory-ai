# Wave1 六个安卓市场企业账号与资质包

状态：**清单已备；六个平台账号、实名认证、资质和提交权限均未核验**

覆盖：华为应用市场、小米应用商店、OPPO软件商店、vivo应用商店、荣耀应用市场、腾讯应用宝。

## 1. 通用账号母包

敏感原件只上传官方平台或进入外部证据库。

- [ ] 最新营业执照原件彩色扫描件，状态正常。
- [ ] 法定名称、USCI、注册地址、法定代表人。
- [ ] 法定代表人身份证明和平台要求的人脸/手机号核验。
- [ ] 经办人身份证明、企业邮箱、实名手机；非法定代表人时准备盖章授权书。
- [ ] 企业域名官网、客服电话、客服/法务/安全邮箱。
- [ ] 对公银行账户、开户证明、税务/开票信息；只有平台实际要求或开通结算时提交。
- [ ] 公司公章和用章审批。
- [ ] APP统一名称、包名、签名指纹、版本。
- [ ] APP备案、网站ICP备案、软著/电子版权、完整授权链。
- [ ] 隐私政策、用户协议、账号注销、投诉下架和AI/模型公示URL。
- [ ] 算法/模型备案、拟人化互动安全评估等适用材料；本包不假定已经取得。

账号安全：

- 每个平台使用独立的公司控制账号和企业邮箱。
- 开启MFA；恢复码进入双人控制的密码库。
- 密码、验证码、身份证和银行卡不得写入Git、工单正文或普通聊天。
- Account Owner与日常操作员分离，授予最小权限。
- 记录账号ID、主体、注册邮箱、Owner、恢复人，不记录密码。

## 2. 平台清单

### 2.1 华为应用市场

账号准备：

- [ ] 注册华为开发者账号并选择企业实名认证。
- [ ] 营业执照、法律实体、法定代表人和联系人信息。
- [ ] 按控制台完成法人/联系人身份证或人脸核验。
- [ ] 创建团队并为发布、财务、分析设置最小权限。
- [ ] 如开通数字商品/商户服务，另签协议并准备对公和税务资料。

应用资质：

- [ ] 确认本次是Android分发轨还是HarmonyOS原生轨；两者包体和审核不能相互替代。
- [ ] APP备案、平台当日要求的ICP/软著或电子版权。
- [ ] 包名、签名、APP ID、隐私声明、SDK/权限清单。
- [ ] 漏洞、隐私、兼容性、稳定性和性能测试。

官方未在当前公开入口承诺统一实名认证时限。项目估算2～10个工作日，补件另计。

### 2.2 小米应用商店

账号准备：

- [ ] 使用公司控制的小米账号。
- [ ] 选择真实企业组织类型；小米当前公开标准不接受个人开发者账号申请。
- [ ] 完成法大大企业实名认证。
- [ ] 上传三证合一营业执照；优先原件照片，复印件需盖章且不得遮挡。
- [ ] 企业信息与营业执照、国家公示系统一致。
- [ ] 申请人完成实名认证。
- [ ] 不使用PS、伪造、盗用、马赛克遮挡或限制平台核验的水印。

应用资质：

- [ ] APP备案。
- [ ] 有效ICP证明。
- [ ] 软著或平台明确接受的APP电子版权。
- [ ] 应用主办单位、应用名、包名一致。
- [ ] 适用时提交平台要求的安全评估材料。

小米公开流程说明身份审核通常1～3个工作日；补件和企业认证时间另计。

### 2.3 OPPO软件商店

账号准备：

- [ ] 注册企业开发者账号并完成企业认证。
- [ ] 营业执照、USCI、法定代表人和经办人信息。
- [ ] 按控制台选择当日支持的对公验证、法人核验或人工材料。
- [ ] 经办人非有权人时上传盖章授权。
- [ ] 准备真实联系人、企业邮箱和手机号。

应用资质：

- [ ] APP备案。
- [ ] 软著/平台支持的电子版权和完整授权链。
- [ ] ICP主体与账号主体一致；差异先获取官方书面答复。
- [ ] 平台当日通用/行业承诺函。
- [ ] 中文静态隐私政策URL可直接访问。
- [ ] 权限逐项说明和功能截图。
- [ ] 适用AI备案/安全评估材料。

公开入口没有统一承诺账号审核时限。项目估算2～10个工作日，补件另计。

### 2.4 vivo应用商店

账号准备：

- [ ] 注册公司控制的vivo开放平台账号。
- [ ] 选择企业实名认证，提交营业执照、USCI、法定代表人/经办人信息。
- [ ] 按登录控制台完成手机号、企业邮箱、授权或对公核验。
- [ ] 如需结算，再提交对公银行和税务材料。

应用资质：

- [ ] APP备案、版权证明和适用行业/AI资质。
- [ ] 应用名称、主办者、包名和签名一致。
- [ ] 隐私政策、SDK、权限、账号注销和投诉入口。
- [ ] 从2026年当日控制台导出完整字段，或提交官方工单确认。

公开资料不足以证明2026控制台完整材料和时限。项目估算2～10个工作日；**不得用其他市场要求推断vivo已接受**。

### 2.5 荣耀应用市场

账号准备：

- [ ] 注册荣耀开发者企业账号并完成实名认证。
- [ ] 营业执照、法定代表人/经办人、企业邮箱和手机号。
- [ ] 配置团队角色和发布权限。
- [ ] 如需商户/结算服务，按控制台另交对公和税务材料。

应用资质：

- [ ] APP备案。
- [ ] 软著、APP电子版权或平台当日接受的版权证明。
- [ ] 应用名、备案名、软著名原则上一致；差异先形成证明或官方答复。
- [ ] 隐私政策、SDK/权限、账号注销、AI标识材料。

公开入口没有统一账号审核时限承诺。项目估算2～10个工作日，补件另计。

### 2.6 腾讯应用宝

账号准备：

- [ ] 使用公司控制的腾讯开放平台账号。
- [ ] 选择企业主体，提交营业执照、USCI、法定代表人/管理员信息。
- [ ] 按控制台完成实名手机号、企业邮箱、法人/授权人或对公核验。
- [ ] 经办人准备盖章授权。
- [ ] 如需结算，另交对公银行和税务材料。

应用资质：

- [ ] APP备案、版权证明、ICP/行业资质。
- [ ] 包名、签名、版本和主体一致。
- [ ] 隐私政策、SDK/权限、账号注销、AI显/隐式标识、模型公示和投诉入口。
- [ ] 对2026完整字段提交官方工单并保存答复。

公开资料不足以证明2026控制台完整材料和时限。项目估算2～10个工作日；**不得用旧教程推断应用宝已接受**。
