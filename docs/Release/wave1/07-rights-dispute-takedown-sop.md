## 2. 工单必填字段

- 工单ID、接收时间、渠道、投诉人联系方式。
- 被投诉内容ID、URL、人物/记忆体ID、上传者ID。
- 投诉类型：肖像/姓名/声音/隐私/著作权/近亲属争议/未成年人/冒充/其他。
- 投诉人身份与权利基础；证件只存受控库。
- 请求：停止生成、隐藏、删除、数据副本、说明、其他。
- 紧急性和继续传播风险。
- 原始证据哈希、页面快照、访问日志和当前Feature Flag。
- 每次决定、操作者、时间、通知和复核。

## 4. 处置流程

### 4.1 接收与保全

1. 立即返回工单号，不要求投诉人在公开渠道提交身份证。
2. 保存投诉原文、内容快照、日志、版本和哈希。
3. 证据保全不等于继续公开；对外内容可先下架。
4. 检查同一人物的分享、搜索索引、缓存、生成任务、声音和长期记忆入口。

### 4.2 临时下架

按最小必要原则执行：

- 禁止新生成和新分享。
- 使公开链接返回不可访问状态，并从搜索/推荐中移除。
- 暂停相关人格聊天、声音和长期记忆。
- 保留受控审计副本，不允许运营人员随意下载。
- 向投诉人和上传者分别发送不披露对方敏感信息的通知。

出现权利人冲突时，默认保持离线，不能用“先上线再协商”。

### 4.3 上传者补件

上传者通常在3个工作日内提供：

- 身份和与人物关系。
- 照片/文字/录音来源。
- 著作权、肖像、声音、隐私及近亲属授权。
- 授权范围、期限、地域、商业化和AI生成条款。
- 其他近亲属或共同权利人意见。

无法提供或材料矛盾时维持下架。

### 4.4 决定

可能结论：

- 永久删除并停止处理。
- 维持下架但保留法定/争议审计证据。
- 限制为私人、非生成、非分享状态。
- 补充授权后恢复限定功能。
- 拒绝投诉并说明依据。
- 转交司法、行政机关或外部律师。

决定记录事实、适用规则、证据、范围和复核人；不得写未获得的监管结论。

## 5. 申诉

- 投诉人和上传者均可在收到决定后提交申诉。
- 申诉应有独立工单ID并关联原工单。
- 由未单独作出初次决定的复核人审查。
- 项目目标：5个工作日内回复；复杂权属争议说明延期原因。
- 争议期间默认不恢复公开或生成能力。

恢复必须同时满足：

- [ ] 投诉风险已解决，有书面证据。
- [ ] 法务确认权利基础和授权范围。
- [ ] 隐私/未成年人/AI标识Gate未被绕过。
- [ ] 恢复范围不超过原授权。
- [ ] 投诉人、上传者收到决定通知。
- [ ] 恢复操作者、时间、版本和证据入审计日志。

## 6. 删除与备份

- 生产可见内容、衍生文件、CDN、搜索索引和缓存按清单删除/失效。
- 模型提供商或受托方同步停止处理并返回删除证明。
- 备份按既定周期到期删除；不能即时删除的隔离、禁止恢复到生产并告知请求人。
- 法律争议所需保全与普通产品数据分离，限制访问并设置复核日。
