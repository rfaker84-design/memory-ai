### A3. 程序和文档鉴别材料

按《计算机软件著作权登记办法》准备：

- 源程序前连续30页和后连续30页。
- 任一种文档前连续30页和后连续30页。
- 程序或文档不足60页时提交全部。
- 页码连续，软件全称和版本在页眉/页脚一致。
- 源程序不得包含密钥、令牌、真实用户信息、生产数据库凭据或第三方秘密。
- 代码应来自冻结提交SHA；登记包记录SHA-256。
- 文档应描述真实功能，不把人格聊天、声音或公开广场写成已经公开上线。

申请渠道对每页行数、字体、页眉等格式有当日要求时，以其导出的最新模板为准。
