## 3. 严格限定的测试用途

授权范围仅限：

- 在非公开、受控的内部盲测中比较两种或多种图像处理/生成结果的相似度、自然度或视觉质量。
- 将姓名替换为随机组编号，测试评价者原则上不知道真实身份。
- 由已签署保密义务的内部员工或指定测试人员查看。
- 汇总输出不含真实姓名、原始照片或可反向识别个人的单人评价。

除非另行获得书面单独同意，本授权**不包含**：

- 模型训练、微调、数据集扩充、基准集公开或向模型提供商用于训练。
- 公开展示、作品广场、商店截图、广告、社交媒体或媒体报道。
- 人脸识别、身份认证、监控、画像、医疗或心理结论。
- 声音克隆、视频数字人、商业代言或付费素材销售。
- 将原始照片提供给无合同和数据处理边界的第三方。

## 5. 单独同意

请逐项勾选，默认不勾选：

- [ ] 我单独同意按第4节处理照片中的可识别人脸信息，用于第3节限定的盲测。
- [ ] 我确认已获得照片中其他可识别在世人员的合法授权，或已通过裁剪/遮挡排除。
- [ ] 我同意由下列受托方处理：`________________`；其不得将数据用于自身训练或其他目的。
- [ ] 我确认测试结果只做受控汇总，不公开原始照片和可识别结果。
- [ ] 我理解可在测试结束前撤回；撤回渠道真实可用。

授权人不同意的事项：

- [ ] 不同意模型训练/微调。
- [ ] 不同意公开展示或对外传播。
- [ ] 不同意声音、视频或数字人生成。
- [ ] 不同意用于广告、代言或销售。

本模板默认以上四项均为不同意；任何改动必须重新签署，不能由产品默认开启。

## 6. 权利与争议声明

授权人声明：

1. 已如实说明自己与照片主体、摄影者、著作权人和逝者的关系。
2. 不把“持有照片文件”自动等同于拥有肖像、隐私或著作权。
3. 如收到其他权利人异议，将立即通知运营主体，并接受先暂停/下架再核验。
4. 不要求系统把AI生成结果冒充为照片中的自然人。
5. 本授权不证明任何监管、商店或第三方已经认可该测试。

## 8. 单组准入判定

以下全部满足才可把该组状态从`未签署`改为`可进入盲测`：

- [ ] 授权人身份和权利来源已核验。
- [ ] 在世照片主体的单独同意已签署。
- [ ] 已故主体的近亲属权利声明和其他潜在权利人处理完成。
- [ ] 照片清单、SHA-256、受托方和删除日期完整。
- [ ] 未成年人照片被排除。
- [ ] 受托方合同明确禁止训练和二次使用。
- [ ] 无已知争议或下架请求。
- [ ] 法务/隐私负责人签字。

任一项不满足，状态保持`未授权/暂停`。
