# Sprint 21 每周范围审计与 GO/NO-GO 模板

> 目标发布日期：2026-09-30
> 当前结论：**NO-GO**。本模板不代表任何监管、平台或第三方批准。只有可核验材料和实际状态可以关闭 Gate。

## 1. 固定发布范围

| 范围 | 2026-09-30 处理 | 放行前提 |
|---|---|---|
| 账号、私有记忆录入与管理 | 可作为 1.0 候选 | 主体、备案、隐私、删除、未成年人、商店包体及审核 Gate 全部关闭 |
| 人格聊天 | 仅内测 | 拟人化互动安全评估、算法/模型合规、AI 身份披露、依赖提醒、未成年人隔离、退出与申诉机制通过 |
| 长期记忆驱动聊天 | 仅内测 | 人格聊天 Gate 全部通过，并完成复制/导出/删除和敏感信息影响评估 |
| 声音克隆、合成声音、数字人 | 仅内测 | 单独同意、权利链、显式与元数据标识、撤回与删除、深度合成相关 Gate 通过 |
| 公开作品广场 | **延期到 1.1** | 审核、举报、下架、申诉四项缺一不可；还需值班 SLA 与审计日志 |
| 公开分享链接 | 默认关闭 | 只有完成内容审核、举报、下架、申诉和未成年人边界后才可申请变更 |
| 付费数字内容或 AI 权益 | 条件性剔除 | iOS 未接入合规的应用内购买方案时，不进入 iOS 1.0 公测范围 |

任何一周若产品、代码或商店材料扩大上述范围，必须重新打开相关 Gate；不得用“已开发完成”替代合规放行。

## 3. 每周必审清单

### 3.1 范围与代码漂移

- [ ] 版本号、包名/Bundle ID、功能清单、路由、Feature Flag 与上周基线一致。
- [ ] 未新增公开发布、作品广场、陌生人互动、评论、关注或转发能力。
- [ ] 未把人格聊天、长期记忆、声音或数字人从内测切到公开。
- [ ] 未新增登录方式、支付方式、SDK、权限、模型、算法、数据出境或第三方处理者。
- [ ] 未出现弱化或隐藏 AI 身份的提示词、文案或交互。
- [ ] 若有变化，已更新隐私政策、用户协议、商店数据标签、权限声明和 Gate 台账。

以下变化一经发现，必须在当周重新评审：新 SDK/权限、新模型或模型供应商、新公开分享、新支付/订阅、新登录方式、新敏感信息字段、AI 身份文案变化、未成年人流程变化。

### 3.2 主体、账号和发布包

- [ ] 公司名称、统一社会信用代码、注册地址、联系人和企业邮箱在所有平台一致。
- [ ] D-U-N-S 和 Apple 组织账号状态有可核验回执；未把“申请中”写成“已通过”。
- [ ] 安卓开发者账号实名认证主体与 APP 备案、软著、签名主体一致；差异有官方允许依据。
- [ ] 候选包名、签名证书指纹、版本号、构建号和文件 SHA-256 已记录。
- [ ] 中国大陆 iOS 合规信息、APP 备案信息与包体/商店元数据一致。

### 3.3 备案、知识产权和 AI 合规

- [ ] APP 备案已有真实受理/完成证据，备案号只从官方材料复制。
- [ ] 软件著作权或平台认可的替代材料状态有真实证据；名称和版本无冲突。
- [ ] 实际调用的模型名称、提供方、用途、备案信息和页面披露一致。
- [ ] 是否触发算法备案、生成式 AI 登记/备案、安全评估或拟人化互动安全评估已有书面结论。
- [ ] 需要提交的评估/备案已由正确主体真实发起，证据包含日期和受理机关/平台。
- [ ] 智能对话、合成声音、图片/视频等 AI 内容同时满足显式标识与文件元数据标识要求。

### 3.4 隐私、用户权利和第三方

- [ ] 隐私政策逐项覆盖收集目的、方式、范围、保存期、第三方、跨境、未成年人和联系方式。
- [ ] 首次运行同意、敏感个人信息单独同意、已故者/上传者权利授权可撤回且可审计。
- [ ] SDK 清单、网络抓包、系统权限、商店数据标签和隐私政策一致。
- [ ] 账号删除可在应用内发起，并同时说明处理期限、例外、关联数据与撤回路径。
- [ ] 用户可复制/导出并删除互动数据、记忆、媒体和生成内容。
- [ ] 投诉、举报、下架、申诉均可真实提交、跟踪和留痕，值班人与 SLA 明确。
- [ ] 个人信息保护影响评估、第三方处理协议和数据保留/删除记录已归档。

### 3.5 未成年人、依赖与安全

- [ ] 年龄识别不是仅靠一个“18+”勾选框，且有误判申诉通道。
- [ ] 未成年人不能获得虚拟亲属、虚拟恋人等亲密拟人化互动服务。
- [ ] 监护人/紧急联系人、风险升级和人工处置路径按适用要求落地。
- [ ] 拟人化互动中 AI 身份持续清晰，连续使用提醒、依赖风险提示、便捷退出可测试。
- [ ] 自伤、危机、欺诈、违法内容和纪念对象权利风险有安全策略、人工升级与审计记录。

### 3.6 商业化与商店材料

- [ ] iOS 数字内容/AI 权益使用合规应用内购买；否则从 iOS 候选范围移除。
- [ ] 第三方登录符合 Apple 同等登录选项要求，或已有可核验的例外依据。
- [ ] 图标、截图、预览、描述、关键词、客服/隐私 URL 不含未上线功能或虚假承诺。
- [ ] 年龄分级问卷如实反映社交、UGC、AI 和敏感主题，不以自定“18+”替代平台分级。
- [ ] 各商店审核账号、测试账号、测试说明和功能路径在候选包上可复现。

## 4. 决策规则

1. 任一 **B0 或 B1** 未关闭：结论必须为 **NO-GO**。
2. 证据缺失、编号来源不明、状态只有口头确认：视为未关闭，必须 **NO-GO**。
3. 实际包体、隐私政策、商店元数据或备案主体不一致：必须 **NO-GO**。
4. 人格聊天、长期记忆或声音未通过对应 Gate：只能内测，不能以范围豁免方式公开。
5. 公开作品广场缺少审核、举报、下架、申诉中任一项：必须移至 1.1。
6. B2 仅可由业务负责人和合规负责人书面接受不影响强制要求的剩余风险；B0/B1 不得豁免。
7. “已提交”不等于“已批准”，“商店可见”不等于“监管批准”。报告必须保留原始状态名称。
